# 共有URLを開く

ホーム画面の「追加」タブから、受け取ったしおりURLを開けます。

## 使い方

1. ホーム画面で「追加」を選ぶ
2. `https://tabitabi.pages.dev/...` のURLを貼り付ける
3. 「開く」を押す

現在のしおりURLは次の形式です。

```text
https://tabitabi.pages.dev/{しおりID}
```

編集用リンクでは末尾に `?token=...` が付きます。開くとtokenをブラウザへ保存し、アドレス欄から
token部分を取り除きます。編集用リンク自体を他の人へ転送すると、その人にも編集権限が渡ります。

別サイトのURL、トップページだけのURL、形式が正しくないURLは開けません。

詳しくは[共有リンク・公開・コピー](../common/sharing.md)をご覧ください。
