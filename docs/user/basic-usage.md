# 基本的な使い方

## しおりを作る

[トップページ](/)から旅行のタイトルを入力し、デザインを選んで作成します。編集パスワードは必要な場合に設定できます。

作成したら、URLをブックマークするか、安全な場所に保管してください。最近開いたしおりは端末に記録されますが、ブラウザのデータ削除などで消える場合があります。

## 予定を追加・編集する

しおりの編集画面で予定を追加し、タイトル、日時、場所、メモなどを入力します。表示や入力方法は選択したテーマによって異なります。

予定の順番を調整したり、旅程が決まった後で[別のテーマ](themes.md)に切り替えたりできます。

## しおりを整える

設定からデザインや表示内容を変更できます。旅行メンバー、持ち物、お金の管理なども、対応するテーマや画面で利用できます。

## 共有する

しおりの共有操作からURLを送ります。

- **編集パスワードなし**：閲覧用と編集用のURLを分けず、ひとつのリンクで共有します。URLを知っている人が編集できる場合があります。
- **編集パスワードあり**：閲覧だけの人と、編集を許可する人に合わせてリンクやパスワードを渡します。
- **公開したしおり**：ほかの人に見せるための閲覧ページです。編集が必要な場合はコピー機能を利用できることがあります。

スマートフォンでは、端末の共有メニューが開く場合があります。詳細は[共有リンク・公開・コピー](features/common/sharing.md)をご覧ください。

## あとで開く

[最近のしおり](features/home/recent-items.md)、保存したURL、マイページから開けます。ホーム画面に追加する方法は[PWA](features/home/pwa.md)をご覧ください。

## 印刷する

対応する画面の印刷操作から、印刷やPDFとして保存できます。詳しくは[印刷・PDF保存](features/common/print-pdf.md)をご覧ください。
