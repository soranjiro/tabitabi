# はじめに

「たびたび」は、旅行の予定、メモ、持ち物、お金などをまとめられるWebの旅行しおりです。

## できること

- 予定の日時、場所、種類、メモ、リンクを整理する
- 計画段階や見せ方に合わせてテーマや表示を選ぶ
- 編集パスワードや編集用リンクで編集権限を管理する
- 用途に合わせたリンクでしおりを共有する
- 旅行メンバー、持ち物、予算、立替、精算をまとめる
- 対応する画面から印刷やPDF保存を行う
- 必要に応じてアカウントで保存、公開、コピーを利用する

機能の操作入口はテーマや画面によって異なる場合があります。

## まず試す

1. 「たびたび」をブラウザで開く
2. ホーム画面から新しいしおりを作成する
3. 旅の候補や予定を追加する
4. 必要に応じて編集パスワードを設定する
5. 旅程が固まったら、見やすいテーマや表示へ切り替える
6. 共有する相手に合わせてリンクを選ぶ

新しく作るしおりでは、まず計画を組み立てやすい表示が選ばれます。表示や配色はあとから変更できます。

## アカウントについて

基本的なしおり作成、編集、URL共有はアカウントなしでも利用できます。保存一覧、公開プロフィール、公開しおりのコピーなどを使う場合はアカウントを利用します。

詳しくは[アカウントとマイページ](features/common/account.md)を参照してください。

## PWAとして使う

普段使いでは、PWAとしてホーム画面やアプリ一覧へ追加する使い方をおすすめします。

### iPhone / iPad

Safariの共有メニューから「ホーム画面に追加」を選びます。

### Android

対応ブラウザのメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

### パソコン

対応ブラウザのインストール操作から追加します。

PWAでも、作成、編集、ログインなど通信が必要な操作ではネット接続が必要です。詳しくは[PWA](features/home/pwa.md)を参照してください。
