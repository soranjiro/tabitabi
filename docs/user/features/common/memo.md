# メモ

しおり全体に、予約情報、集合時の注意、旅のメモなどを記録できます。予定ごとのノートとは別です。

## 使い方

1. しおり上部のメモを開く
2. 編集できる状態で内容を入力
3. 「保存」を押す

自動保存ではありません。閉じる前に保存してください。

## Markdown

標準の季節テーマとAI Generatedでは、見出し、箇条書き、チェックボックス、太字、リンクなどの
Markdownを表示できます。標準テーマではHTMLを安全な許可リストで整形し、画像タグは表示しません。

書き方は[Markdown](../themes/markdown.md)をご覧ください。

## 共有時の注意

- 元しおりの閲覧用・編集用リンクでは、メモをそのまま共有する
- 公開用リンクでは、メールアドレス、電話番号、予約番号、部屋番号らしい文字列を自動的に伏せる
- 自動判定ですべての個人情報を見つけられるとは限らない
- お金、持ち物、旅行メンバーは公開用スナップショットへ含めない

公開前に、住所、氏名、予約番号、連絡先などが残っていないか自分でも確認してください。
