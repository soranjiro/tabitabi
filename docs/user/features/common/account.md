# アカウントとマイページ

アカウントは任意です。しおりの基本作成・編集は登録なしで使えます。

## アカウントでできること

- 作成したしおりをマイページへ保存
- 同じアカウントで保存一覧を確認
- ユーザー名と都道府県を変更
- メールアドレスとアカウントパスワードを変更
- 公開プロフィールへしおりを掲載
- 「みんなのしおり」で他の利用者を検索
- 公開された閲覧専用しおりを自分用にコピー

アカウントへの保存と、しおりの編集権限は別です。保存一覧にある鍵付きしおりでも、編集には
しおりパスワードまたは編集用リンクが必要です。

## 新規登録

1. ホーム右上のマイページを開く
2. 「新規登録」を選ぶ
3. ユーザー名、メールアドレス、8文字以上のパスワード、都道府県を入力
4. 届いた確認メールのリンクを開く
5. マイページへ戻り「確認が完了しました」を押す

ユーザー名は3〜20文字の半角英数字と `_` が使用できます。ユーザー名は公開され、
メールアドレスと都道府県は公開プロフィールに表示されません。

## 既存のしおりを同期する

ログインすると、そのブラウザに編集token付きで保存されている通常しおりをマイページへ同期します。
最近閲覧しただけで編集権限がないしおりは同期対象になりません。一度に同期する件数には上限があり、
多い場合は分割して処理されます。

ログイン中に新しく作ったしおりは、自動的に「公開オフ」で保存一覧へ追加されます。ここでの
公開オフは公開プロフィールと「みんなのしおり」へ掲載しない意味で、しおり自体へのアクセス制限ではありません。

## 公開プロフィール

公開プロフィールにはユーザー名と、公開をオンにしたしおりの閲覧専用スナップショットを表示します。
メールアドレス、都道府県、元しおり、編集tokenは表示しません。

## 設定変更

マイページの「アカウント設定」から変更できます。

- プロフィール: ユーザー名、都道府県
- メール変更: 新しいアドレスに届く確認リンクを開いて確定
- パスワード: 現在のパスワードで再認証して変更

## パスワードを忘れた

ログイン画面の「パスワードを忘れた方」から再設定メールを送れます。これはFirebaseアカウントの
パスワードです。しおりごとの編集パスワードは再設定できません。
