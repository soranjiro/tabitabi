# 表示モード

同じ旅程データを、目的に合わせて異なる見せ方で確認できます。

## 主な見せ方

| 表示 | 向いている使い方 |
|---|---|
| 日カード | 日ごとの流れを順番に見る |
| セクションカード | 旅程全体をまとまりごとに見る |
| リスト | 予定をコンパクトに並べる |
| 週ビュー | 時間帯や予定の重なりを見る |
| 月ビュー | 月全体を俯瞰する |

実際に選択できる表示は、アプリのテーマ選択・表示設定画面を基準にしてください。

表示を変えても、共通の予定やメモは同じしおりのデータとして利用されます。終日予定や複数日にまたがる予定などは、表示方法によってレイアウトが変わります。
