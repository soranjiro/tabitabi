# 基本的な使い方

## しおりを作る

ホーム画面からタイトルを入力して、しおりを作成します。作成後は、旅の候補や予定、メモなどを追加できます。

しおりはアカウントなしでも作成できます。アカウント機能を利用している場合は、保存一覧から管理できます。

> [!IMPORTANT]
> アカウントなしで利用する場合は、しおりURLや編集に必要な情報を自分で管理してください。共有範囲を限定したい場合は編集パスワードを設定してください。

## 予定を追加する

編集できる状態で、予定の追加操作から必要な情報を入力します。

- タイトル
- 開始・終了日時
- 終日予定かどうか
- 予定の種類
- 場所
- メモ
- 関連リンク

テーマによって入力画面や表示方法は異なりますが、基本となる旅程データは共通です。

## 閲覧と編集

しおりには、閲覧だけを行う状態と、内容を変更できる編集状態があります。編集パスワードや編集用リンクを利用している場合は、それらを持つ人だけが編集できます。

公開されたしおりは閲覧を前提として扱い、編集したい場合は利用可能なコピー機能を使って自分用のしおりを作成します。

詳しくは[編集パスワードと編集モード](features/common/auth.md)を参照してください。

## しおりを整える

編集画面の設定から、テーマ、配色、表示方法、旅行メンバーなどを変更できます。利用できる設定はテーマによって異なります。

テーマを変更しても、共通の予定やメモは同じしおりのデータとして利用されます。

## メモを書く

しおり全体のメモや予定ごとのノートを使って、集合場所、予約情報、注意事項などを整理できます。共有するしおりへ個人情報や機密情報を書く場合は、共有範囲に注意してください。

## 共有する

共有画面から、用途に合ったリンクを選びます。

| 方法 | 用途 |
|---|---|
| 閲覧向け | 内容を確認してもらう |
| 編集向け | 一緒に内容を変更する |
| 公開向け | 広く見てもらう |

編集用リンクは編集権限につながるため、公開ページやSNSへ載せないでください。詳しくは[共有リンク・公開・コピー](features/common/sharing.md)を参照してください。

## 旅の準備をまとめる

対応する画面では、旅行メンバー、持ち物、予算、支出、立替、精算などを管理できます。操作入口が見つからない場合は、別のテーマや表示も確認してください。

## 印刷・PDF保存

印刷に対応する画面から印刷用レイアウトを開き、ブラウザやOSの印刷機能を使って印刷またはPDF保存します。

## あとで開く

普段使いではPWAとしてインストールして、ホーム画面やアプリ一覧から開く方法をおすすめします。ほかにも、最近のしおり、アカウントの保存一覧、共有されたURL、ブラウザのブックマークなどから開けます。
