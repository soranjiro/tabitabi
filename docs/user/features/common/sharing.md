# 共有リンク・公開・コピー

しおりは、目的に合わせて閲覧、編集、公開などの方法で共有します。利用できる共有操作は、開いている画面や権限によって異なります。

## 共有方法を選ぶ

| 種類 | 向いている用途 | 注意 |
|---|---|---|
| 閲覧向け | 内容を確認してもらう | 編集制限の設定も確認する |
| 編集向け | 一緒に旅程を変更する | 編集権限として扱い、公開しない |
| 公開向け | 広く見てもらう | 公開前に内容を目視確認する |

編集制限を設定していないしおりでは、閲覧向けのURLから編集できる場合があります。閲覧だけに限定したい場合は、編集パスワードや公開向けの方法を利用してください。

## 公開するとき

公開向けのしおりでは、元のしおりをそのまま編集可能な状態で公開しないように設計されています。ただし、個人情報を自動的に見つけて除く処理だけに頼らないでください。

公開前には、少なくとも次を確認してください。

- 氏名、住所、連絡先
- 予約番号やチケット情報
- 宿泊先の部屋番号
- 第三者へ見せたくないメモやリンク

## 公開しおりをコピーする

コピー機能が利用できる公開しおりは、自分用のしおりとして複製して編集できます。コピー後のしおりは元のしおりとは別に扱われます。

## 安全に共有する

- 編集用リンクをSNSや公開ページへ載せない
- 公開範囲に合わせて編集パスワードを利用する
- 公開前後に内容を目視確認する
- 共有先を間違えた場合は、画面にある権限・公開設定を確認し、必要に応じて新しい共有方法へ切り替える
