# 使い方

「たびたび」は、旅の予定やメモ、持ち物、お金をひとつのしおりにまとめて、家族や友だちと共有できるアプリです。

## はじめて使う方へ

1. [しおりを作る](user/getting-started.md) — 旅のタイトルとデザインを選ぶ
2. [予定を追加・編集する](user/basic-usage.md) — 日時や場所をまとめる
3. [しおりを共有する](user/features/common/sharing.md) — 一緒に見る・編集する
4. [テーマを選ぶ](user/themes.md) — 旅に合わせて表示を変える

## やりたいことから探す

- **旅の準備** — [持ち物リスト](user/features/common/packing.md)・[お金の管理](user/features/common/money.md)・[旅行メンバー](user/features/common/members.md)
- **しおりの共有** — [共有リンク](user/features/common/sharing.md)・[編集パスワード](user/features/common/auth.md)・[シークレットモード](user/features/themes/secret-mode.md)
- **便利な使い方** — [メモ](user/features/common/memo.md)・[印刷とPDF](user/features/common/print-pdf.md)・[ホーム画面に追加](user/features/home/pwa.md)
- **アカウント** — [ログイン・マイページ](user/features/common/account.md)・[最近のしおり](user/features/home/recent-items.md)

詳しい項目は[機能一覧](user/features/index.md)から確認できます。操作に困ったら[よくある質問](user/faq.md)をご覧ください。

## 共有するときの注意

しおりのURLを知っている人は内容を見られます。編集パスワードを設定していないしおりは、URLから編集できる場合もあります。公開する前に、連絡先や予約番号などが含まれていないか確認してください。
