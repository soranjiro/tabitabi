# Markdown

標準の季節テーマとAI Generatedでは、しおりメモと予定ノートにMarkdownを使えます。

## よく使う記法

### 見出し

```markdown
# 大見出し
## 中見出し
### 小見出し
```

### 箇条書きと番号

```markdown
- パスポート
- 充電器

1. 空港へ移動
2. チェックイン
```

### チェックボックス

```markdown
- [x] ホテルを予約
- [ ] 切符を購入
```

### 強調、引用、コード

```markdown
**必ず持参**
*雨天時のみ*
> 集合は改札の外
`ABC-123`
```

### リンク

```markdown
[ホテル公式サイト](https://example.com)
```

標準テーマでは、表、取り消し線、水平線などGFMの一部も表示できます。テーマによって見た目や
対応範囲が異なります。

## 安全性と制限

- 入力したHTMLは許可されたタグ・属性だけを残す
- `javascript:`、`data:` など危険なURL schemeは除去する
- 画像タグは許可されないため、Markdown画像は表示されない
- チェックボックスは表示用で、クリックして本文を自動更新するものではない
- AI Generatedは標準テーマより簡易的なMarkdown実装

外部サイトへのリンクは、確認画面や別表示を経由することがあります。
