# PWA（ホーム画面へ追加）

「たびたび」は、対応ブラウザでホーム画面やアプリ一覧へ追加できます。

## メリット

- アイコンから起動できる
- 対応端末ではブラウザ枠の少ないstandalone表示になる
- 静的ファイルは端末へキャッシュされ、再表示が速くなる
- 過去に読み込んだGET画面・データは、通信失敗時にキャッシュから開ける場合がある

## インストール

### iPhone / iPad（Safari）

1. Safariでサイトを開く
2. 共有ボタンをタップ
3. 「ホーム画面に追加」を選ぶ
4. 「追加」をタップ

### Android（Chrome）

1. Chromeでサイトを開く
2. メニューから「アプリをインストール」または「ホーム画面に追加」を選ぶ

### パソコン

Chromeなど対応ブラウザのアドレスバー付近にあるインストールアイコンを選びます。

## オフラインについて

完全なオフラインアプリではありません。

- まだ開いていないしおりや地図は表示できない
- 新規作成、編集、共有、ログインはネット接続が必要
- オフライン中の変更をあとで自動送信する機能はない
- ブラウザやOSがキャッシュを削除すると利用できなくなる

インストールしても、しおり本体はサーバーへ保存されます。PWAをアンインストールしても
サーバー上のしおりは削除されません。
