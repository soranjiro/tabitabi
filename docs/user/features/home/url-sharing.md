# 共有URLを開く

受け取った「たびたび」のしおりURLは、そのままブラウザやPWAで開けます。ホーム画面にURL入力機能が表示されている場合は、そこへ貼り付けて開くこともできます。

## 使い方

1. 共有されたしおりURLをコピーする
2. ブラウザまたはPWAで開く
3. 必要に応じて閲覧または編集モードへ進む

編集用リンクには編集に必要な情報が含まれる場合があります。編集用リンクを転送すると、受け取った人にも編集権限が渡る可能性があるため、公開ページやSNSへ載せないでください。

URLのホスト名や形式は配信環境によって変わる可能性があるため、このドキュメントでは固定のドメイン形式を前提にしません。

詳しくは[共有リンク・公開・コピー](../common/sharing.md)を参照してください。
