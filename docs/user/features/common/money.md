# お金の管理

対応する画面では、旅行予算、支出予定、支払い済みの支出、立替、共同基金、精算などを管理できます。

## 準備

先に[旅行メンバー](members.md)を登録すると、支払った人や費用を負担する人を設定できます。

## 予算

旅行全体の予算を設定し、確定した支出、予定している支出、残りの予算を確認できます。

## 支出

支出には、内容、金額、支払い状況、支払った人、負担する人、日付、関連する予定などを設定できます。

複数人で費用を負担する場合は、均等に分ける方法や、メンバーごとに異なる金額を設定する方法を利用できます。

## 共同基金

旅行前に集めたお金や、基金から支払った費用、返金などをまとめて管理できます。表示される残高を確認しながら入出金を記録してください。

## 精算

支払った金額と負担する金額をもとに、メンバー間の精算額を確認できます。

精算結果は登録内容をもとに計算されるため、支払者、負担者、支払い状況を正しく設定してください。
