# 編集パスワードと編集モード

しおりの編集パスワードは、内容を閲覧するためのものではなく、内容を変更できる人を限定するための機能です。アカウントへログインするパスワードとは別に扱います。

## パスワードを設定しない場合

編集制限を設けないしおりでは、URLを知っている人が編集できる場合があります。少人数で気軽に共同編集するときに向いています。

第三者による編集を避けたい場合は、編集パスワードを設定してください。

## パスワードを設定する場合

編集モードへ入るときにパスワードを確認します。認証後は、編集に必要な情報がブラウザへ保存される場合があります。

共有端末を使う場合や、ブラウザのサイトデータを削除する場合は、編集権限を再確認できるように必要な情報を管理してください。

## 編集用リンク

編集用リンクを受け取った人は、パスワード入力なしで編集できる場合があります。編集用リンクはパスワードと同じように秘密として扱い、公開ページやSNSへ載せないでください。

## 編集できないとき

1. 編集用リンクを持っている場合は、もう一度そのリンクを開く
2. 編集パスワードを設定している場合は、正しいパスワードを確認する
3. 公開用の閲覧ページを開いていないか確認する
4. ブラウザのサイトデータを削除していないか確認する

アカウントへのログインだけで、すべてのしおりの編集権限が得られるわけではありません。
