# 予定表・プラン比較

## 操作

- 「予定」は全予定の一覧、「プラン比較」は分岐・合流を含むタイムライン。同じ予定を編集する。
- 予定を選んで「ここから分岐」、末尾の「次の予定」でルートを延長する。「別の出発点」は独立した別行動に使う。
- ルート名は右側パネルで編集。参加者・参考金額は予定単位で登録する。複数通貨は換算せず別々に集計し、共通の予定の金額はルート集計に含めない。
- 「別プランへ移動」で挿入直前の予定を選ぶ。対象の予定だけを移動し、元のルートの前後をつなぎ直す。分岐点・合流点は対象外。時刻が前後する場合は先に日時を修正する。
- 候補の選択は検討状態の保存。「選択案をこの予定に反映」でタイトル・指定された日時・場所を既存予定へ反映する。予定を複製せず、他の候補も保持する。
- スマートフォンはルート名付きの時系列カード。PCでは接続線を描く。折りたたみは表示だけの変更。

## 保存とテーマ

通常予定の正本は `Step`。分岐の接続とルート名、参加者・参考金額、複数候補と選択IDは `itinerary_plan_graphs` に保存する。Step IDで対応付け、描画時はStepの最新タイトル・日時を優先する。グラフの保存時にも最新Step値を使う。参加者・金額のみの編集で日時精度や既存メモを書き換えない。

テーマ変更ではStep・グラフを削除しない。他テーマでは全プランの予定を時系列で表示する。予定表に戻すと分岐・候補・参加者を再表示し、他テーマで行った通常予定の編集も反映する。未採用の候補は独立したStepにはしない。削除されたStepの古いメタ情報から予定を復活させない。

実データのグラフ更新はrevisionによる楽観的排他。競合時はエラーを表示し、再読込後に再編集する。APIは循環・日時逆転・不正接続・サイズなどを検証する。

## 公開・プレビュー

`SharedBook` はグラフも含めてローカルに保持する。公開前のプレビューは予定表を表示し、元テーマ表示にも切り替えられる。公開済みのしおりでも「予定表で編集」から同じ操作を試せる。操作は元のしおりへ保存せず、コピーまたは明示的な共有版保存時に内容を渡す。

公開時は参加者名・予約URL・予約情報を除去したスナップショットを作る。プレビューで追加した予定を含め、グラフの接続先を公開先Step IDへ変換する。コピー時も新しいStep IDへ変換する。テーマを変えてもローカルのグラフ状態は維持する。

操作サンプル: `/demo/planning-comparison`。サンプルデータと変更はブラウザのsessionStorageに保存し、APIへ書き込まない。「最初に戻す」でリセットできる。

## 検証

- `make test-api`: 公開・コピー時のID変換、公開前プレビューの除去処理、テーマ往復と既存Step保存を検証。
- `make test-web`: 移動時のつなぎ直し、日時逆転・分岐点の拒否など。Node 26での実行は `NODE_OPTIONS=--no-experimental-webstorage make test-web`。
- `make test-planning-comparison`: 実APIを使うE2EとAPIへの書込みなしのサンプル操作。デプロイ先は `PLAYWRIGHT_BASE_URL` と `PREVIEW_API_URL` で指定できる。PRプレビューのsmokeテストにも登録。


## 挿入・移動・合流の操作（改善版）

- PCでは予定間の「＋」から、新しい予定作成、既存予定の挿入／複製、分岐、既存予定への合流を選ぶ。先頭と末尾にも「＋」がある。モバイルでは各カード間の追加ボタンから、同じ操作をボトムシートで選べる。
- 「既存の予定を挿入」は**同じStepを別の位置へ移動**し、旧位置の前後をつなぎ直す。「既存の予定を複製」はフォームを事前入力し、新しいStepとして保存する。同じ予定の二重作成はしない。共有分岐点・合流点の移動は明示的に拒否し、既存接続を壊さない。
- 合流は「既存予定に合流」から接続先カードを直接タップ／クリックして実行する。循環・日時逆転・同一接続は拒否する。カードが遠くにある場合は従来の合流先選択も利用できる。
- PCではカードをドラッグして他の予定の上半分にドロップすると前、下半分なら後に移動する。モバイル・キーボードでは予定操作パネルの「別プランへ移動」から前後の位置を選べる。
- 線形の旅程で全予定に日時がある場合、最新の開始日時（同時刻はStepのsort_order）を使って自動整列する。分岐・合流を含むグラフは接続の意味を勝手に変更しない。日時未定の予定は挿入・移動した位置を維持する。
- グラフの接続・移動は「元に戻す」で一手戻せる。Stepの新規作成や削除はグラフだけ戻して孤立したStepを残さないようUndoの対象から除外する。
- 編集パネルはPCでは右サイドバーの上部、モバイルでは閉じられるボトムシートで表示する。常時右下に浮く小さな操作画面は使用しない。

これらは既存の予定一覧、候補比較、公開前プレビューのStepを再利用し、グラフ更新はAPIのrevision検査とDAG検証に従う。
