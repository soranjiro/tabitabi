# 使い方ガイド

「たびたび」は、旅行の予定やメモ、持ち物、お金をひとつのしおりにまとめて共有できるサービスです。

## おすすめの使い方

日常的に利用する場合は、PWAとしてホーム画面やアプリ一覧へ追加する使い方をおすすめします。インストール方法は[PWA](features/home/pwa.md)を参照してください。

## まず読む

1. [はじめに](getting-started.md) — できることと利用開始まで
2. [基本的な使い方](basic-usage.md) — 作成、編集、共有
3. [テーマの選び方](themes.md) — 計画段階や見せ方に合わせた表示
4. [PWA](features/home/pwa.md) — ホーム画面やアプリ一覧への追加

アカウントは、しおりの基本的な作成や共有だけであれば必須ではありません。保存一覧、公開プロフィール、公開しおりのコピーなど、アカウント向け機能を使う場合に登録してください。

## 安全に共有する

編集用リンクや編集パスワードは、編集を許可する相手だけに共有してください。公開する内容には、連絡先、予約情報、住所など第三者へ見せたくない情報を含めないようにしてください。
