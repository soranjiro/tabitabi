# 共有リンク・公開・コピー

しおりの共有操作から、家族や友だちにURLを送れます。

## 編集パスワードを設定していない場合

共有リンクはひとつです。閲覧用と編集用を分ける必要はありません。

**URLを知っている人が編集できる場合があります。** 閲覧だけに限定したい場合は、編集パスワードを設定するか、公開向けの共有方法を利用してください。

## 編集パスワードを設定した場合

共有する相手に合わせて、閲覧用リンクと編集用の情報を使い分けます。編集用リンクやパスワードは、編集を許可する相手だけに渡してください。

スマートフォンでは端末の共有メニューから送れる場合があります。パソコンなどではリンクをコピーして送ります。

[編集パスワードと編集モード](auth.md)

## 公開する場合

公開しおりは、広く見てもらうための閲覧ページです。公開前に、氏名、住所、連絡先、予約番号などを含んでいないか確認してください。

公開用の処理があっても、個人情報が必ず自動で取り除かれるとは限りません。

## 公開しおりをコピーする

コピー機能がある公開しおりは、自分用のしおりとして複製できます。複製したしおりは元のしおりとは別に編集できます。

編集用リンクはSNSや公開ページへ載せないでください。
