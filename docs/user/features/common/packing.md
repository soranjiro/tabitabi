# 持ち物リスト

標準の季節テーマで、旅行メンバーごとの準備とグループ共通の荷物を管理できます。

## 最初に旅行メンバーを登録する

「持ち物」を開き、表示された案内から旅行メンバーを登録します。「この旅では誰ですか？」で
この端末を使う自分を選ぶと、「自分」タブに自分向けの項目が表示されます。

## 3種類の持ち物

| 種類 | 表示とチェック |
|---|---|
| 自分専用 | 選んだ所有者のリストだけに表示 |
| 各自で持つ | 同じ項目を全員がそれぞれチェック |
| 誰か1人が持つ | グループで1つだけ用意し、担当者を設定可能 |

持ち物名、1〜10個の数量、グループを設定できます。

## グループ

初期グループは次の5つです。

- 貴重品
- スマホ・電子機器
- 洗面・ケアアイテム
- 衣類
- その他

編集できる人はグループを追加・改名・削除できます。グループを削除すると、その中の持ち物は
残っている別グループへ移動します。最後の1グループを削除した場合は「その他」が作られます。

## 画面の見方

- 「自分」: 自分専用、各自で持つ項目、自分が担当する共通品
- 「みんな」: メンバーごとの準備状況、共通品の全一覧

チェック状態はしおりへ保存されます。鍵付きしおりでは、編集権限がある人だけ変更できます。

旅行メンバーを削除すると、その人の自分専用アイテムとチェック状態も削除されます。共通品は
削除されず、削除した人が担当者だった場合は未担当へ戻ります。
