# PWA

「たびたび」は、対応ブラウザからホーム画面やアプリ一覧へ追加して利用できます。

普段使いでは、PWAとして追加する方法をおすすめします。しおりを確認したいときにブラウザのタブやブックマークを探さず、アプリに近い形で起動できます。

## PWAを使うメリット

- ホーム画面やアプリ一覧から直接起動できる
- 対応端末ではブラウザのUIを抑えた表示で使える
- アプリ本体の静的ファイルがキャッシュされ、再表示しやすくなる
- 一度取得した画面やGETデータは、通信できないときにキャッシュから表示できる場合がある

## 追加する

### iPhone / iPad

1. Safariで「たびたび」を開く
2. 共有メニューを開く
3. 「ホーム画面に追加」を選ぶ
4. 追加を確定する

### Android

1. 対応ブラウザで「たびたび」を開く
2. ブラウザのメニューを開く
3. 「アプリをインストール」または「ホーム画面に追加」を選ぶ

### パソコン

対応ブラウザのインストール操作から追加します。表示名や場所はブラウザによって異なります。

## オフラインについて

PWAは完全なオフライン編集アプリではありません。

- 新しいデータの取得には通信が必要になる場合がある
- 作成、編集、共有、ログインなどサーバーへ反映する操作にはネット接続が必要
- オフライン中の変更をあとから自動送信する仕組みは前提にしない
- キャッシュはブラウザやOSの管理により削除される場合がある

PWAは「インストールして使いやすくする」ための機能として利用し、重要なしおりはサーバーへの保存が完了したことを確認してください。
