# 予定表の種類アイコン設計（単色SVG）

## 背景と課題

予定の種類を選ぶときに、視認性・画面間の一貫性・意味の分かりやすさを改善する。

旧UIには以下の問題があった。

1. **意味が直接伝わらない**：🎌を「観光」とするのは連想が難しい。🚄は新幹線に限定して見える。🚗「一般的な移動」と🚙「車」も似すぎている。
2. **同じ予定でも画面によって異なる**：選択はSVG、一覧は絵文字、地図はSVG、詳細は別表示で、同じ種類か確認しづらかった。船・徒歩などがデフォルトに丸められる表示漏れもあった。
3. **絵文字にしたところかえって見づらい**：OSごとに字形・配色が変わり、色が強いため小さい画面では情報が散らばる。特に地図で色付き絵文字とピン色が重なり、種類の識別よりも装飾が目立った。
4. **「一般的な予定」は冗長**：何を選べばよいかわからない。「その他」にし、補足を「ほかの種類に当てはまらない予定」とする。
5. **選択肢が隠れる**：横スクロールの奥に候補が隠れていた。2〜3列のグリッドで全種類を見渡せるようにする。
6. **細い線や密な装飾**：小さいアイコンで細部の多い表現は判別できない。アイコンを24×24 viewBox・2px線・角丸線端で統一する。

## 最終的な方針

- **絵文字は使わず、静的な単色SVGだけに統一する。** SVGは `standard/core/utils/step-type-svg.ts` に集約し、SvelteコンポーネントとLeafletの地図ピンで同じ定義を使う。色は `currentColor`、ベースは濃いグレー。OSによる絵柄・色の差がない。
- **見分けは色ではなく輪郭で**：その他＝カレンダー、食事＝フォークとナイフ、宿泊＝ベッド、観光＝ランドマーク、買い物＝バッグ、その他の移動＝歩く人、電車＝車両、車＝乗用車、飛行機＝飛行機、バス＝車体、船＝船体。
- **ピンも色分けしない**：白地に濃色アイコンの同一デザインで統一。選択中のみ濃色背景・白線と外枠で状態を示す。タイトルラベルとタップで識別を補助。
- **種類の文字は必須**：選択画面はSVG＋短い日本語ラベル、選択時に意味を説明する文章を表示。一覧は各予定タイトル、詳細は種類の日本語ラベル、地図はできるだけ予定タイトルを併記。
- **既存データは維持**：`normal:general` などの保存IDを変更しない。`normal:meal` は食事と同じ表示。未指定や未知の種類は「その他／カレンダーSVG」にフォールバックする。
- **範囲を絞る**：予定表（planning-draft および互換の planning-map）で選択、予定一覧、詳細、地図に適用。共通Pickerも同じSVGを利用する。スタイルや既存の保存処理は不必要に変更しない。

## SVGの実装・安全性

Svelteでは `StepTypeIcon.svelte` が静的なSVGを描画する。LeafletのマーカーはSvelteコンポーネントを差し込めないため、同じ `getStepTypeSvg(type)` の戻り値をマーカーのHTMLとして利用する。この関数は**固定のコード内文字列のみ**を返し、予定タイトルなど利用者入力は挿入しない。タイトルは別途HTMLエスケープする。

## 検証

- 単色SVGのみ・色指定なし・各選択可能な種類が異なるSVGであること。
- 未指定・未知種別・旧食事種別でも適切にフォールバックすること。
- モバイル320/375/430px・PCで選択肢が隠れないこと、文字が崩れないこと、選択状態が色だけに依存しないこと。
- 予定追加/編集後も種類が維持され、選択・一覧・詳細・地図で同じ輪郭が表示されること。
- 地図のピン・タイトルラベルのタップ、重なり回避、キーボード操作が維持されること。
