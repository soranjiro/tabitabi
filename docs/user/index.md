# 使い方ガイド

「たびたび」は、旅程・メモ・持ち物・お金をひとつのしおりにまとめ、同行者との共有や次の旅の参考探しまでできる旅行しおりサービスです。

## まずはここから

1. [はじめに](getting-started.md) — できることと利用開始まで
2. [基本的な使い方](basic-usage.md) — 作成、予定追加、共有、公開
3. [テーマの選び方](themes.md) — 旅程の見せ方と色を選ぶ

しおりの作成・編集だけならアカウント登録は必須ではありません。アカウントを作ると、保存したしおりをマイページで管理したり、「みんなのしおり」へ公開したり、公開された旅程をコピーして自分用に編集したりできます。

## 安全に共有するために

編集を特定の人だけに限定したいしおりには編集パスワードを設定してください。「みんなのしおり」へ公開するときは、元のしおりではなく閲覧専用の公開スナップショットが作られます。
