# Japan prefecture map attribution

The SVG map files in this directory are derived from
[Geolonia/japanese-prefectures](https://github.com/geolonia/japanese-prefectures),
which is based on prefecture maps from Japanese Wikipedia and distributed under
the GNU Free Documentation License (GFDL).

- `japan-prefectures.svg`: derived from `map-full.svg`
- `japan-prefectures-mobile.svg`: derived from `map-mobile.svg`

The original SVG metadata and prefecture grouping are retained. Interactive
colors and navigation behavior are applied by tabitabi at runtime.
