# 持ち物リスト

対応する画面では、旅行メンバーごとの準備と、グループ共通の荷物を管理できます。

## 持ち物の考え方

| 種類 | 用途 |
|---|---|
| 自分専用 | 特定のメンバーだけが持つもの |
| 各自で持つ | 同じ項目を各メンバーが準備するもの |
| 誰か1人が持つ | グループで1つ用意するもの |

持ち物には、名前、数量、グループ、担当者などを設定できます。

## メンバーとの連携

先に[旅行メンバー](members.md)を登録すると、個人ごとの持ち物や担当者を設定しやすくなります。

端末で「自分」を選ぶと、自分に関係する持ち物をまとめて確認できます。

## グループ

持ち物はカテゴリや用途ごとのグループへ整理できます。追加、名称変更、並べ替えなど、利用できる操作は画面に表示される内容を基準にしてください。

## チェック状態

準備状況はしおりへ保存されます。編集制限を設定している場合は、編集権限を持つ人だけが変更できます。
