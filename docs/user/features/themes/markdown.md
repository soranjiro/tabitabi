# Markdown

Markdownに対応するメモや予定ノートでは、文章を見出しや箇条書きなどで整理できます。対応範囲や見た目はテーマによって異なります。

## よく使う記法

### 見出し

```markdown
# 大見出し
## 中見出し
### 小見出し
```

### 箇条書きと番号

```markdown
- パスポート
- 充電器

1. 空港へ移動
2. チェックイン
```

### チェックボックス

```markdown
- [x] ホテルを予約
- [ ] 切符を購入
```

### 強調、引用、コード

```markdown
**必ず持参**
*雨天時のみ*
> 集合は改札の外
`ABC-123`
```

### リンク

```markdown
[ホテル公式サイト](https://example.com)
```

## 安全性と制限

Markdownの表示では、安全のためHTMLやURLの一部が制限される場合があります。画像など、対応していない記法は表示されないことがあります。

外部サイトへのリンクを共有する場合は、リンク先も含めて公開してよい内容か確認してください。
