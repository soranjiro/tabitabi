# たびたび

旅の予定、メモ、持ち物、お金などをひとつのしおりにまとめて、共有できる旅行しおりアプリです。

普段使いでは、対応ブラウザからPWAとしてホーム画面やアプリ一覧へ追加する使い方をおすすめします。ブラウザのタブを探さずに起動でき、アプリに近い形で利用できます。

## ガイド

### アプリを使う

しおりの作成、共有、テーマ、PWA、各機能の使い方は[使い方ガイド](user/index.md)を参照してください。

### 開発に参加する

環境構築、アーキテクチャ、機能開発、テーマ開発、テストは[開発者ガイド](developer/index.md)を参照してください。

## 主な機能

| 機能 | 説明 |
|---|---|
| 旅程管理 | 日時、場所、メモ、リンクなどをまとめて管理 |
| 表示の切り替え | 旅の段階や見せ方に合わせて表示を選択 |
| PWA | ホーム画面やアプリ一覧から起動 |
| 共有 | 閲覧、編集、公開など用途に合わせて共有 |
| 旅の準備 | メンバー、持ち物、予算、立替、精算を管理 |
| アカウント | 必要に応じて保存、公開、コピーなどを利用 |

機能の表示位置や利用できる操作は、選択しているテーマや画面によって異なる場合があります。
