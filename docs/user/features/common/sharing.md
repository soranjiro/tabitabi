# 共有リンク・公開・コピー

標準テーマでは、しおりの「メニュー」→「共有」から3種類のリンクを使い分けられます。

## リンクの違い

| 種類 | 内容 | 編集 |
|---|---|---|
| 閲覧用リンク | 元しおりURL。編集tokenなし | 鍵付きは不可、鍵なしは可能 |
| 編集用リンク | 元しおりURL + 編集token | 可能 |
| 公開用リンク | 個人情報らしい文字列を伏せた別の閲覧専用しおり | 不可。ログイン後にコピー可能 |

「閲覧用」という名前でも、元しおりに編集パスワードがなければ誰でも編集できます。閲覧だけに
したい場合は編集パスワードを設定するか、公開用リンクを使ってください。

## 公開用リンク

公開用リンクを作ると、元しおりとは別に閲覧専用のスナップショットを作ります。

- タイトル、テーマ、初期表示、予定、メモをコピー
- メールアドレス、電話番号、予約番号、部屋番号らしい文字列を `[非公開]` に置換
- 予定のHTTP(S)リンクは残り、公開画面ではアフィリエイト表示を含むことがある
- 編集パスワード、シークレット設定、Walica、旅行メンバー、お金、持ち物は含めない
- 元しおりを更新しても自動では変わらない

マイページで公開しているしおりには「最新版を公開」ボタンが表示されます。内容を更新したら、
このボタンでスナップショットを更新してください。自動除去は完全ではないため、公開前後に必ず
自分で内容を確認してください。

## 「みんなのしおり」へ公開する

1. アカウント登録とメール確認を完了する
2. マイページの「保存したしおり」を開く
3. 対象しおりの「公開」をオンにする
4. 公開プロフィールまたは「みんなのしおり」で表示を確認する

公開をオフにすると一覧から非表示になります。公開対象は閲覧専用スナップショットで、元しおりの
編集用tokenやパスワードは掲載されません。

## 公開しおりをコピーする

公開用リンクを開くと「コピーして編集」が表示されます。コピーにはログインとプロフィール設定が
必要です。コピー先にはタイトル、テーマ、初期表示、メモ、予定が入り、タイトル末尾に「（コピー）」
が付きます。シークレット設定とWalicaは引き継がれません。

コピーは元しおりと独立しています。コピー後の変更は元しおりへ反映されません。

## 安全に共有する

- 編集用リンクをSNSや公開ページへ載せない
- 元しおりへ機密情報を書く場合、共有相手を限定する
- 一般公開には公開用リンクを使い、伏せ字を目視確認する
- 現在は発行済み編集tokenを個別に失効できない。誤って公開した場合は、そのリンクを持つ人が最長30日編集できる前提で内容を確認する
