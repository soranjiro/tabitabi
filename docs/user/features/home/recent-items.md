# 最近のしおり

最近開いたしおりへ、ホーム画面から戻るための履歴です。

## 仕組み

履歴は端末やブラウザ側に保存されます。アカウントの保存一覧とは別の仕組みです。

同じ端末でも、別のブラウザやプライベートブラウズでは同じ履歴が表示されない場合があります。サイトデータを削除すると、履歴や端末に保存されていた編集情報も失われる場合があります。

## 大切なしおりを残す

普段使いではPWAとしてホーム画面やアプリ一覧へ追加すると、サービス自体を開きやすくなります。

しおりを確実に見つけられるようにするには、用途に応じて次も利用してください。

- アカウントの保存一覧
- 共有されたしおりURL
- 編集用リンクの安全な保管
- ブラウザのブックマーク

「最近のしおり」から履歴を削除しても、しおり本体の削除とは限りません。しおり本体に関する操作は、対象のしおりやアカウント画面に表示される操作を基準にしてください。
