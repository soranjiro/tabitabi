# メモ

しおり全体に、集合時の注意、予約情報、旅のメモなどを記録できます。予定ごとのノートとは別に管理されます。

## 使い方

1. しおりのメモを開く
2. 編集できる状態で内容を入力する
3. 保存操作を行う

自動保存ではない画面では、閉じる前に保存が完了したことを確認してください。

## Markdown

Markdownに対応する画面では、見出し、箇条書き、チェックボックス、太字、リンクなどを利用できます。テーマによって表示や対応範囲が異なります。

書き方は[Markdown](../themes/markdown.md)を参照してください。

## 共有時の注意

公開や共有の前に、住所、氏名、連絡先、予約番号など第三者へ見せたくない情報が残っていないか確認してください。自動的な伏せ字や公開用変換がある場合でも、最終確認は利用者自身で行ってください。
