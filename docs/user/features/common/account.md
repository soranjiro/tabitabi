# アカウントとマイページ

アカウントは任意です。しおりの基本的な作成や編集は、アカウントなしでも利用できます。

## アカウントでできること

- 作成したしおりを保存一覧で管理する
- 同じアカウントから保存したしおりを確認する
- プロフィールを設定する
- 公開するしおりを管理する
- 公開されたしおりを自分用にコピーする

アカウントに保存されていることと、しおりを編集できることは別の権限です。編集パスワードや編集用リンクを設定したしおりでは、必要な編集権限を別途確認してください。

## 登録とログイン

マイページから新規登録またはログインを行います。登録に必要な項目や確認手順は、画面に表示される案内に従ってください。

## 保存一覧

ログイン中に作成または保存したしおりは、マイページから確認できます。端末内の「最近のしおり」とアカウントの保存一覧は別の仕組みです。

## 公開プロフィール

公開を選んだしおりは、公開プロフィールや公開一覧に表示される場合があります。公開前に、第三者へ見せたくない情報が含まれていないか確認してください。

## 設定変更

プロフィール、メールアドレス、アカウントパスワードなど、変更可能な項目はアカウント設定から操作します。

しおりごとの編集パスワードは、アカウントパスワードとは別です。
