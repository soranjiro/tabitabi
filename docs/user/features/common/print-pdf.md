# 印刷・PDF保存

印刷に対応する画面では、しおりを印刷用に整えて、プリンターへ出力したりPDFとして保存したりできます。

## 使い方

1. しおりのメニューから印刷・PDFの操作を開く
2. 利用できるレイアウトを選ぶ
3. プレビューを確認する
4. ブラウザやOSの印刷画面を開く
5. プリンターまたはPDF保存を選ぶ

利用できるレイアウトや操作入口は、テーマ、旅程の長さ、画面サイズなどによって異なる場合があります。表示されている選択肢を基準にしてください。

## きれいに保存するコツ

- 用紙サイズや向きをプレビューに合わせる
- 必要に応じて背景の印刷を有効にする
- 長い旅程ではページ分割を確認する
- スマートフォンで作成した場合も、保存後のPDFを確認する

印刷画面の名称やPDF保存方法はOS・ブラウザによって異なります。
