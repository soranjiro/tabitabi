# テーマと表示の選び方

テーマは、旅程の見せ方や操作方法を切り替えるための仕組みです。選択できるテーマと配色はアプリ側で管理されているため、実際の選択画面に表示される内容を基準にしてください。

## 計画を始めるとき

新しいしおりでは、候補を集めながら日付や時間を決めやすい計画向けの表示から始められます。

行きたい場所ややりたいことを先に追加し、旅程が固まってから見せ方を切り替える使い方がおすすめです。

## 旅程を見るとき

旅程が固まったら、目的に合う表示を選びます。たとえば次のような見せ方があります。

| 表示 | 向いている使い方 |
|---|---|
| 日カード | 日ごとの予定を順番に見る |
| セクションカード | 旅程全体をまとまりごとに見る |
| リスト | 予定をコンパクトに並べる |
| 週ビュー | 時間帯や重なりを確認する |
| 月ビュー | 月全体を俯瞰する |

選べる表示はアプリの更新に合わせて変わることがあります。ドキュメントでは個別テーマの全一覧を固定せず、作成画面やテーマ変更画面を正本とします。

## 配色

表示方法と配色は別に選べます。旅の雰囲気や読みやすさに合わせて変更してください。

## 機能の違い

テーマや表示によって、持ち物、お金、印刷、地図、Markdownなどの操作入口や対応範囲が異なる場合があります。

必要な機能が見つからない場合は、別の表示へ切り替えるか、[機能一覧](features/index.md)を確認してください。

## 変更する

編集できる状態でテーマや表示の設定を開き、別のものを選びます。共通の予定やメモは同じしおりのデータとして利用されます。

## デモ

ホーム画面にテーマや表示を試す機能がある場合は、実際のしおりを作成する前に操作感を確認できます。
