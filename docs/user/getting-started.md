# はじめに

「たびたび」は、旅行の予定、メモ、持ち物、お金をまとめられるWebの旅しおりです。

## できること

- 日時、場所、種類、メモ、関連リンクを付けて予定を整理
- 旅に合うテーマと表示方法を選択
- 編集パスワードで、閲覧だけの人と編集できる人を分ける
- 閲覧用、編集用、個人情報を伏せた公開用リンクを共有
- 旅行メンバー、持ち物、予算、立替、精算を管理（標準テーマ）
- しおりを印刷またはPDF保存（標準テーマ／Map Only）
- 任意のアカウントでしおりを保存・公開・コピー

## まず試す

1. [たびたび](https://tabitabi.pages.dev)をブラウザで開く
2. ホームの「作成」タブでタイトルを入力
3. テーマを選ぶ
4. 必要なら「パスワードで保護する」をオンにして編集用パスワードを入力
5. 「しおりを作成」を押す
6. 「予定を追加」から日時や場所を登録する

Web画面の既定テーマは「標準（春）」です。あとから、編集できる状態でしおり設定を開くと
テーマを変更できます。

## アカウントは必要？

基本的なしおり作成、編集、URL共有はアカウントなしで利用できます。アカウントは次の場合に必要です。

- 作成済みしおりをマイページへ保存・同期したい
- 「みんなのしおり」や自分の公開プロフィールへ掲載したい
- 公開された閲覧専用しおりをコピーして編集したい

登録では、メールアドレス、8文字以上のパスワード、3〜20文字の英数字または `_` のユーザー名、
都道府県を入力します。確認メール内のリンクを開いて登録を完了してください。都道府県と
メールアドレスは公開プロフィールには表示されません。

詳しくは[アカウントとマイページ](features/common/account.md)をご覧ください。

## アプリのように使う

PWAとしてホーム画面へ追加できます。

### iPhone / iPad（Safari）

1. Safariの共有ボタンをタップ
2. 「ホーム画面に追加」を選択
3. 「追加」をタップ

### Android（Chrome）

1. Chromeのメニューを開く
2. 「アプリをインストール」または「ホーム画面に追加」を選択

### パソコン（Chromeなど）

アドレスバー付近のインストールアイコンから追加します。ブラウザによって表示や対応状況は異なります。

一度開いた画面や素材はキャッシュされることがありますが、完全なオフライン編集には対応していません。
詳しくは[PWA](features/home/pwa.md)をご覧ください。
