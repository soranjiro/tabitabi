# 編集パスワードと編集モード

しおりごとの編集パスワードは、内容を見せたまま変更だけを制限する機能です。アカウントへ
ログインするパスワードとは別です。

## パスワードなし

- URLを知っている人は閲覧できる
- URLを知っている人は編集モードにも切り替えられる
- 気軽な共同編集向け

鍵なししおりには「所有者」というサーバー上の概念がないため、アカウントへ保存していても
他の人の編集を止めることはできません。

## パスワードあり

- URLだけを知る人は閲覧できる
- 編集モードへ入るときにパスワードが必要
- 認証後は、しおり専用の編集tokenをブラウザへ保存
- tokenの有効期間は30日

パスワードはサーバーでbcryptハッシュとして保存されます。パスワードそのものを確認する機能はありません。

## 編集用リンク

編集用リンクには編集tokenが含まれます。受け取った人はパスワードを入力せず編集できるため、
編集パスワードと同じように秘密として扱ってください。共有後に相手のブラウザへ保存されたtokenを
遠隔で消す機能はありません。

## パスワードを変更・解除する

現在の利用者向け画面には、作成後の編集パスワード変更・解除機能がありません。パスワードを
忘れた場合や共有範囲を作り直したい場合は、新しいしおりを作成してください。

## 編集モードに入れないとき

1. 編集用リンクをもう一度開く
2. パスワード付きなら正しい編集パスワードを入力する
3. ブラウザのサイトデータを消していないか確認する
4. 公開用リンクではないか確認する（公開スナップショットは常に閲覧専用）

アカウントにログインしているだけでは、鍵付きしおりの編集権限は復元されません。
