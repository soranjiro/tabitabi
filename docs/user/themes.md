# テーマの選び方

テーマは見た目だけでなく、操作方法や利用できる機能も変わります。あとから変更できますが、
特定テーマ専用の設定は別テーマに表示されないことがあります。

## 標準テーマ

初めて使う場合は「標準（春）」がおすすめです。春・夏・秋・冬は配色だけが異なり、
次の機能を共通で利用できます。

- 日カード、リスト、月、週の4表示
- 予定、終日予定、複数日予定、種類アイコン、リンク
- メモとMarkdown
- 旅行メンバー、持ち物、お金・精算
- シークレットモード
- 閲覧用・編集用・公開用リンク
- 3種類の印刷・PDFデザイン

| テーマ | 雰囲気 |
|---|---|
| 標準（春） | 桜をイメージしたやさしいピンク。新規作成時の既定 |
| 標準（夏） | 爽やかな青 |
| 標準（秋） | 温かく落ち着いた茶・橙 |
| 標準（冬） | 静かで凛とした青 |

## 特化テーマ

| テーマ | 向いている使い方 | 主な特徴 |
|---|---|---|
| Map Only | 場所を中心に考えたい | Google Maps、場所マーカー、地図中心UI、印刷 |
| Mapbox Journey | 移動ルートを眺めたい | Mapboxの3D地図・グローブ |
| AI Generated | タイムラインを華やかに見せたい | Markdown、シークレット、独自レイアウト |
| 買い物リスト | 買い物やお使い | アイテム中心のUI |
| ピクセルクエスト | 旅程をゲーム風に楽しみたい | レトロRPG風マップ |
| サウナスタンプラリー | サウナ巡り | スタンプラリー風UI |

特化テーマは標準テーマの持ち物、お金、4種類の表示をすべて備えているとは限りません。
必要なデータを入力できるか、ホームの「テーマを試す」からデモで確認してください。

Map OnlyにはGoogle Maps、Mapbox JourneyにはMapboxの読み込みが必要です。通信環境や
ブラウザ設定によって地図が表示されない場合があります。

## テーマを変更する

標準テーマでは、編集モードで「メニュー」→「しおり設定」→「テーマ」を開きます。
テーマを選ぶと同じしおりを新しい表示で開きます。予定やメモは共通データなので残りますが、
テーマ固有の操作は対応テーマでだけ表示されます。

## デモで試す

ホーム画面の「テーマを試す」からデモを開けます。デモでの変更はブラウザ内だけに保存され、
通常のしおりやサーバーのデータには反映されません。
