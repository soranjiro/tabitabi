# よくある質問

## 利用とアカウント

### アカウント登録は必要ですか？

基本的なしおり作成、編集、URL共有はアカウントなしでも利用できます。保存一覧、公開プロフィール、公開しおりのコピーなど、アカウント向け機能を使う場合に登録してください。

### アカウントのパスワードと編集パスワードは同じですか？

別です。アカウントのパスワードはログインに使い、編集パスワードは個別のしおりの編集を制限するために使います。

### しおりの編集パスワードを忘れました

編集用リンクや、ブラウザに保存されている編集権限が利用できるか確認してください。編集権限を復元できない場合は、画面に表示される案内に従ってください。

## データと共有

### URLを知っている人に見られますか？

共有したしおりURLは、受け取った人が開ける前提で扱ってください。編集パスワードは主に編集を制限するための機能です。第三者へ見せたくない情報は、しおりへ保存しないか、共有前に削除してください。

### 公開時に個人情報は自動で消えますか？

公開用の変換が行われる場合でも、自動判定だけで完全に除去できるとは限りません。公開前後に、氏名、住所、連絡先、予約番号などが残っていないか自分で確認してください。

### バックアップできますか？

印刷・PDF保存に対応する画面では、旅行の確認用としてPDFを保存できます。データとしてのバックアップ方法は、アプリに表示される利用可能な機能を基準にしてください。

## 編集と共有

### 閲覧向けのURLなのに編集できます

編集制限を設定していないしおりでは、URLを知っている人が編集できる場合があります。閲覧だけに限定したい場合は編集パスワードを設定するか、公開向けの共有方法を利用してください。

### 編集用リンクを共有するとどうなりますか？

編集用リンクは編集権限につながる情報です。編集してよい相手だけへ送り、SNSや公開ページへ載せないでください。

### 複数人で編集できますか？

同じしおりを複数人で編集できますが、同じ項目を同時に変更した場合は後から保存した内容が優先されることがあります。

## テーマと機能

### テーマや表示は後から変更できますか？

はい。編集できる状態で、利用可能なテーマや表示へ切り替えられます。共通の予定やメモは同じしおりのデータとして利用されます。

### 機能が見つかりません

テーマや表示によって操作入口や対応範囲が異なる場合があります。[機能一覧](features/index.md)と[テーマと表示の選び方](themes.md)を確認してください。

## PWAとトラブル

### PWAとして使うのがおすすめですか？

はい。普段使いではPWAとしてホーム画面やアプリ一覧へ追加する方法をおすすめします。詳しくは[PWA](features/home/pwa.md)を参照してください。

### オフラインでも使えますか？

一度取得した画面やデータがキャッシュから表示される場合はありますが、完全なオフライン利用は前提としていません。作成、編集、共有、ログインなどサーバーへ反映する操作にはネット接続が必要です。

### 最近のしおりや編集権限が消えました

端末やブラウザに保存される情報は、サイトデータの削除、別ブラウザ、別端末、プライベートブラウズなどでは引き継がれない場合があります。

### データが保存されません

1. ネット接続を確認する
2. 編集できる状態か確認する
3. ページを再読み込みしてもう一度試す
4. 解決しなければ、操作内容と利用環境を添えてIssueまたはフィードバックから報告する

## 問い合わせ

アプリ内のフィードバック機能、または[GitHub Issues](https://github.com/soranjiro/tabitabi/issues)から報告してください。公開Issueへ編集用リンク、メールアドレス、予約番号などを書かないでください。
