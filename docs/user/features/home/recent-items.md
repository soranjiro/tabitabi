# 最近のしおり

同じブラウザで開いたしおりを、ホームからすばやく開くための履歴です。

## 仕組み

- ブラウザのlocalStorageへ最大10件を保存
- 最後に開いたものを先頭に表示
- しおりID、タイトル、最終アクセス時刻、編集tokenなどを端末内に保持
- 履歴から個別に削除可能

## 注意点

- ブラウザのサイトデータを削除すると履歴と保存済み編集tokenも消える
- シークレット／プライベートブラウズでは保持されないことがある
- 別のブラウザや端末へ履歴そのものは同期されない
- 履歴から削除してもしおりのサーバーデータは削除されない

ログインすると、編集tokenを持つ通常しおりをマイページの保存一覧へ同期します。単に閲覧しただけの
しおりは同期されません。大切なしおりは、マイページへの保存、編集用URLの安全な保管、ブラウザの
ブックマークを組み合わせてください。
