# 旅行メンバー

旅行メンバーは、持ち物やお金の管理で使う、しおり内の参加者情報です。サービスへログインするアカウントとは別です。

## メンバーを追加する

編集できる状態で、しおり設定や各機能の案内からメンバーを追加します。

端末で「自分」として選んだメンバーは、持ち物などの個人向け表示に利用されます。この選択は端末やブラウザごとに異なる場合があります。

## 使われる場所

- 持ち物の所有者や担当者
- 個人ごとの準備状況
- 支払った人、負担する人
- 予算や精算の計算

## 変更・削除

名前を変更しても、関連するデータとの紐づけは維持されます。

支出や持ち物から参照されているメンバーを削除するときは、関連データの変更が必要になる場合があります。画面に表示される案内に従ってください。
