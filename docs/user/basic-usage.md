# 基本的な使い方

## しおりを作る

ホーム画面の「作成」タブで次を入力します。

- タイトル（必須、100文字まで）
- テーマ
- 編集パスワード（任意）

「しおりを作成」を押すと `https://tabitabi.pages.dev/{しおりID}` のページが開きます。
作成したブラウザには編集権限が保存されます。

> [!IMPORTANT]
> アカウントなしで使う場合、しおりURLと編集権限は自分で管理してください。ブラウザデータを
> 消すと編集権限を失うことがあります。大切なしおりは編集用リンクも安全な場所へ保管してください。

## 予定を追加する

標準テーマでは「予定を追加」を押し、次を入力します。

- タイトル
- 開始日・開始時刻、終了日・終了時刻
- 終日予定かどうか
- 予定の種類（食事、宿泊、観光、買い物、電車、飛行機など）
- 場所
- メモ
- 関連するWebリンク

保存した予定をタップすると詳細を確認でき、編集できる状態なら変更・削除できます。
テーマによって入力画面や利用できる項目は異なります。

## 閲覧モードと編集モード

- 鍵なしの通常しおり: URLを知っている人は編集モードへ切り替え可能
- 鍵付きしおり: パスワードまたは編集用リンクを持つ人だけ編集可能
- 公開用リンクのしおり: 常に閲覧専用。コピー後のしおりは編集可能

標準テーマでは「メニュー」から閲覧／編集を切り替えます。パスワード認証後の編集権限は
ブラウザに保存され、tokenの有効期間は30日です。

## しおりを整える

標準テーマの「しおり設定」では次を変更できます。

- 旅行メンバー
- テーマ
- 開いたときの初期表示（日カード、リスト、月、週）
- シークレットモードと公開タイミング

画面下の「持ち物」「お金」「表示」から、旅支度や表示を切り替えられます。

## メモを書く

しおり上部のメモを開いて編集し、「保存」を押します。標準テーマとAI Generatedでは
Markdownを利用できます。予約番号や連絡先などを記録する場合は、共有範囲に注意してください。

## 共有する

標準テーマでは「メニュー」→「共有」からリンクを選びます。

| リンク | 用途 |
|---|---|
| 閲覧用 | tokenを含まない元しおりURL |
| 公開用 | 個人情報らしい文字列を伏せた閲覧専用コピー |
| 編集用 | 編集tokenを含むURL。受け取った人も編集できる |

鍵なしの元しおりは、閲覧用URLだけでも誰でも編集できます。編集を制限したい場合は、共有前に
編集パスワードを設定してください。編集用リンクはパスワードと同じように秘密として扱います。

公開用リンクの詳しい違いは[共有リンク・公開・コピー](features/common/sharing.md)をご覧ください。

## 印刷・PDF保存

標準テーマまたはMap Onlyの「印刷・PDF出力」から、週間プラン、デザイナーズしおり、
詳細タイムラインを選べます。「印刷 / PDF保存」を押し、ブラウザの印刷画面でプリンターまたは
PDF保存を選びます。

## しおりをあとで開く

- 同じブラウザ: ホームの「最近のしおり」
- URLを受け取った: ホームの「追加」タブへ貼り付け
- ログイン中: マイページの「保存したしおり」
- 手動保存: ブラウザのブックマーク

最近のしおりは端末のブラウザ内に保存されます。アカウントの保存一覧とは別です。
