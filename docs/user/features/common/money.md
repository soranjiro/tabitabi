# お金の管理

標準の季節テーマで、旅行予算、共同基金、支出予定、支払い済み、立替と精算を管理できます。

## 準備

先に[旅行メンバー](members.md)を登録します。画面下の「お金」を開くと、同じメンバーが表示されます。

## 予算

詳細設定から旅行全体の予算を円で入力します。表示は次を切り替えられます。

- 全体
- 1人あたり（登録メンバー数で換算）

確定支出、予定支出、残り予算を分けて確認できます。

## 共同基金

「精算・内訳」の共同基金で、メンバーから集めたお金を入金として登録できます。基金からメンバーへ
お金を戻したときは返金として登録します。現在の残高は、入金から返金と基金払いの確定支出を引いた金額です。

支出の支払い方法で「共同基金から支払う」を選ぶと、その支出を基金残高から差し引きます。
残高が不足するとマイナスで表示されるため、追加で必要な入金も確認できます。

## 支出を登録する

| 項目 | 内容 |
|---|---|
| 内容 | ホテル、交通費など |
| 金額 | 1円以上の整数 |
| 区分 | 支払い済み、支出予定 |
| 支払い方法 | 立替した人、各自で支払う、または共同基金から支払う |
| 負担 | 費用を負担するメンバーと、均等または一人ずつ異なる負担額 |
| 予定との紐づけ | 任意のしおり予定 |
| 日付 | 任意の支出日 |

支出予定は、支払い後に「立替済みにする」で確定支出へ変更できます。

「個別」を選ぶと、大人と子どもで料金が違う場合や、一部のメンバーだけ追加料金がある場合などに、
一人ずつ負担額を入力できます。入力した負担額の合計は、支出の総額と一致する必要があります。
同じ負担額のメンバーは1つのグループにまとまり、まとめて金額を変更できます。違う金額にする人は
「別額」を押してグループから分けます。

## 精算

「精算・内訳」では、各メンバーが払った金額と負担すべき金額から、誰が誰へいくら渡すかを
自動計算します。共同基金への入金・返金と基金払いも計算に含めるため、旅行終了時に基金から返す金額や
基金へ追加する金額も確認できます。支出予定と「精算済み」にした立替支出は、現在の精算額に含めません。

「各自で支払う」は立替が発生しない支出として扱います。負担するメンバーと金額を正しく設定してください。

支払者または負担者として使われているメンバーは、先に該当する支出を変更または削除するまで
メンバー一覧から削除できません。名前の変更では支出との紐づけは維持されます。
