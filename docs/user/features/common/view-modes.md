# 表示モード

標準の季節テーマでは、同じ予定を4種類の表示で確認できます。

| 表示 | 向いている使い方 |
|---|---|
| 日カード | 日ごとに写真カードのように予定を見る |
| リスト | 全予定を時系列でコンパクトに見る |
| 月カレンダー | 旅行前後を含む月全体を俯瞰する |
| 週ビュー | 1週間の時間帯と重なりを確認する |

画面下の「表示」から一時的に切り替えられます。

## 初期表示を変える

編集モードで「メニュー」→「しおり設定」→「初期表示」を開き、4種類から選びます。
保存後、そのしおりを開いたときの表示が選んだモードになります。初期値は日カードです。

表示モードを変えても予定データは変わりません。終日予定、複数日にまたがる予定、同時刻の予定は
表示ごとにレイアウトが異なります。
