## たびたびの特徴

| 特徴 | 説明 |
|------|------|
| 🎨 多彩なテーマ | 旅のスタイルに合わせてデザインを選択 |
| 📱 PWA対応 | アプリのようにインストールして使える |
| 🔒 パスワード保護 | 編集権限を管理できる |
| 🔗 3種類の共有 | 閲覧・編集・公開用のリンクを使い分けられる |
| 🎒 旅の管理 | 持ち物、予算、立替、精算をまとめて管理 |
| 👤 任意のアカウント | 登録なしで作成でき、登録すると保存・公開・コピーが使える |
