# シークレットモード

対応する画面では、予定開始が近づくまで閲覧者へ予定内容を隠すシークレットモードを利用できます。

## 仕組み

シークレットモードでは、設定した公開タイミングまでは予定の詳細を伏せ、時刻が近づくと表示します。編集権限を持つ人には、編集のために内容が表示されます。

## 設定する

1. 編集できる状態でしおり設定を開く
2. シークレットモードを有効にする
3. 公開タイミングを選ぶ

利用できる公開タイミングは画面に表示される選択肢を基準にしてください。

## 注意点

- 予定の日時が正しくないと、意図しないタイミングで表示される
- 一度見た人による保存や撮影までは防げない
- 公開用のしおりでは同じ設定が適用されない場合がある

シークレットモードは旅の演出を補助する機能であり、機密情報を安全に保管するための機能ではありません。
