# ChatGPTとたびたびの連携

旅行の予定はChatGPTで相談し、完成したしおりはたびたびで共有できます。

## しおりから「ChatGPTで考える」

1. たびたびで編集したいしおりを開きます。
2. 画面の「メニュー」から **ChatGPTで考える** を選びます。
3. 既存の予定を含めるかを選び、相談したいことを書きます。
4. **ChatGPTでこのしおりを編集** から、現在のしおりを指定した下書きを開きます。

ChatGPTアプリの状態によっては下書きが表示されないことがあります。その場合は **プロンプトをコピー** して貼り付けてください。MCPを接続しなくても旅の相談はできます。

## アカウントのしおりをChatGPTで見る・編集する

本人確認を完了したたびたびのアカウントがあれば、ChatGPTのMCP連携によって、アカウントに保存したしおりの一覧や予定を確認できます。

1. ChatGPTの連携設定で、たびたびのMCPサーバーを追加します。サーバーURLは \`https://tabitabi-api.oranda.workers.dev/mcp\` です。
2. 接続画面で、たびたびアカウントにログインして連携を許可します。
3. ChatGPTに「たびたびに保存しているしおりを一覧表示して」と伝えます。
4. しおりを選ぶと詳細を確認できます。編集権限を持つしおりなら、予定の追加・変更も依頼できます。

一覧には「編集できるか」が表示されます。**アカウントに保存しただけでは編集権限は得られません。** 元から編集できるしおりを開いて編集権限をアカウントに紐付けてください。パスワード付きしおりの予定は、編集権限がなければMCPに公開されません。

連携にはChatGPT側でカスタムMCPサーバーを追加できる環境が必要です。たびたびに登録しただけでChatGPTに自動接続されるわけではありません。

## プライバシー

「ChatGPTで考える」では、しおりのURLと、許可した場合の予定タイトル・日時・場所だけが下書きに含まれます。メモ、編集用トークン、パスワード、非表示の予定は引き継ぎません。外部サービスに渡す情報を送信前に確認してください。
