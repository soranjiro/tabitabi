# 旅行メンバー

標準の季節テーマでは、同じ旅行メンバーを持ち物とお金の管理で共通して使います。

## メンバーを追加する

1. 編集モードに入る
2. 「メニュー」→「しおり設定」を開く
3. 「旅行メンバー」で名前を追加する

持ち物画面で「この旅では誰ですか？」と表示されたときも、メンバーを選択または追加できます。
「自分」の選択はその端末のブラウザに保存されます。

## 使われる場所

- 持ち物: 自分専用、各自のチェック状況、共通品の担当者
- お金: 支払った人、負担する人、1人あたり予算、精算額

## 名前を変更・削除する

設定から変更できます。支出の支払者・負担者や共通の持ち物の担当者として使われているメンバーは、
先に関連する項目を変更または削除する必要があります。個人ごとの持ち物チェックもメンバーに紐づきます。

メンバーはサービスのアカウントではありません。メールアドレスやログイン権限は持たず、
しおり内の表示名としてだけ使います。
