# はじめに

「たびたび」では、旅行の予定をひとつのしおりにまとめて共有できます。

## しおりを作る

1. [トップページ](/)を開く
2. 旅行のタイトルを入力する
3. 好きなデザインを選ぶ
4. 必要に応じて編集パスワードを設定し、しおりを作成する
5. 予定やメモを追加する

作成後も、デザインや予定を変更できます。操作は[基本的な使い方](basic-usage.md)をご覧ください。

## 共有する

しおりの共有操作からURLを送り、家族や友だちに見てもらえます。パスワードを設定した場合は、編集を許可する人だけに編集用の情報を伝えてください。

詳しくは[共有リンク・公開・コピー](features/common/sharing.md)をご覧ください。

## アカウントは必要？

しおりの作成やURLでの共有は、ログインせずに利用できます。マイページでの管理や公開など、一部の機能ではログインが必要です。

[アカウントとマイページ](features/common/account.md)

## いつでも開けるようにする

対応するスマートフォンやパソコンでは、ホーム画面やアプリ一覧に追加できます。通信が必要な操作もあるため、完全なオフライン利用には対応していません。

[ホーム画面に追加する方法](features/home/pwa.md)
