# シークレットモード

予定開始が近づくまで、閲覧者に予定内容を隠す機能です。標準の季節テーマとAI Generatedで
利用できます。

## 仕組み

シークレットモードはしおり全体に適用されます。予定ごとに秘密かどうかを選ぶ方式ではありません。

```text
公開時刻 = 予定の開始時刻 - 設定した時間
```

たとえば12:00開始の予定を「1時間前」に設定すると、11:00までは内容を隠し、11:00以降に公開します。

隠れている間はタイトルを `?????` などで表示し、場所、ノート、リンクを返しません。日時や予定枠は
表示されます。編集権限を持つ人には常に内容を表示します。

## 設定する

1. 編集モードに入る
2. 「しおり設定」を開く
3. シークレットモードをオンにする
4. 公開タイミングを選ぶ

選択肢は、予定時刻、15分前、30分前、1時間前、2時間前、3時間前、5時間前、12時間前、24時間前です。

## 注意点

- 予定の日時が正しくないと、意図しない時刻に公開される
- 端末時刻だけでなくAPI側でも現在時刻を使って内容を伏せる
- 公開用スナップショットにはシークレット設定を引き継がない
- 一度見た人が内容を保存・撮影することまでは防げない

サプライズ用の補助機能であり、機密情報の保管機能ではありません。
