# 印刷・PDF保存

標準の季節テーマとMap Onlyでは、しおりをA4向けに整えて印刷またはPDF保存できます。

## 使い方

1. しおりのメニューを開く
2. 「印刷・PDF出力」を選ぶ
3. デザインを選ぶ
4. プレビューを確認
5. 「印刷 / PDF保存」を押す
6. ブラウザの印刷画面でプリンターまたはPDF保存を選ぶ

## デザイン

| デザイン | 向き | 特徴 |
|---|---|---|
| 週間プラン | 横 | 1週間を横並び。予定が多い日は続きページへ分割 |
| デザイナーズしおり | 縦 | 表紙と日別の雑誌風レイアウト |
| 詳細タイムライン | 縦 | 場所とメモを含む長い旅程向け |

デザイナーズしおりは、4日以内、予定24件以内、1日6件以内などの条件を超えると選択できません。
長いメモを含む場合も、詳細タイムラインを利用してください。

## きれいに保存するコツ

- 印刷画面の用紙をA4にする
- ブラウザが指定する縦／横をそのまま使う
- 必要に応じて「背景のグラフィック」を有効にする
- スマートフォンではプレビューが縮小されるため、最終PDFも確認する

印刷画面の名称やPDF保存方法はOS・ブラウザによって異なります。
