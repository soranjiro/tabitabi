# 基本的な使い方

## しおりを作る

ホーム画面の「次の旅を、つくろう。」からタイトルを入力し、しおりを作成します。
作成後はそのまましおり画面へ移動し、予定や旅の情報を追加できます。

しおりはアカウントなしでも作成できます。ログインしている場合は、作成したしおりがマイページにも保存されます。

> [!IMPORTANT]
> アカウントなしで使う場合、しおりURLと編集権限は自分で管理してください。ブラウザデータを
> 消すと編集権限を失うことがあります。編集を制限したいしおりには編集パスワードを設定してください。

## 予定を追加する

標準テーマでは「予定を追加」を押し、次を入力します。

- タイトル
- 開始日・開始時刻、終了日・終了時刻
- 終日予定かどうか
- 予定の種類（食事、宿泊、観光、買い物、電車、飛行機など）
- 場所
- メモ
- 関連するWebリンク

保存した予定をタップすると詳細を確認でき、編集できる状態なら変更・削除できます。
テーマによって表示方法は変わりますが、同じ旅程データを利用します。

## 閲覧モードと編集モード

- 鍵なしの通常しおり: URLを知っている人は編集モードへ切り替え可能
- 鍵付きしおり: パスワードまたは編集用リンクを持つ人だけ編集可能
- 「みんなのしおり」に公開されたしおり: 閲覧専用。コピーすると自分用のしおりとして編集可能

標準テーマでは「メニュー」から閲覧／編集を切り替えます。編集を特定の人だけに限定したい場合は、
共有前に編集パスワードを設定してください。

## しおりを整える

標準テーマの「しおり設定」では、次の内容をまとめて変更できます。

- 旅行先とタグ
- 旅行メンバー
- デザインテーマ
- しおりの色
- 持ち物管理の表示
- シークレットモードと予定の表示開始タイミング

テーマを変更すると、日カード・リスト・月・週など、そのテーマに合った旅程の見せ方へ切り替わります。

## メモを書く

しおり上部のメモを開いて編集し、「保存」を押します。Markdownを利用できるテーマでは、
見出しや箇条書き、リンクなどを使って情報を整理できます。予約番号や連絡先などを記録する場合は、共有範囲に注意してください。

## 共有する

標準テーマでは「メニュー」→「共有」からリンクを利用できます。

| 方法 | 用途 |
|---|---|
| 閲覧用リンク | tokenを含まない元しおりURL |
| 編集用リンク | 編集tokenを含むURL。受け取った人も編集できる |
| みんなのしおりへ公開 | 個人情報らしい文字列を伏せた閲覧専用スナップショットを公開 |

公開にはアカウントが必要です。公開時には旅行先・エリア・タグを設定し、公開されたページからは元のしおりを直接編集できません。
気になる公開しおりはコピーして、自分の旅程として編集できます。

詳しくは[共有リンク・公開・コピー](features/common/sharing.md)をご覧ください。

## 持ち物とお金を管理する

標準テーマでは画面下部から、旅のメンバーを使った持ち物管理とお金の管理を利用できます。
持ち物管理はしおり設定から表示・非表示を切り替えられます。

## 印刷・PDF保存

対応テーマの「印刷・PDF出力」からレイアウトを選び、ブラウザの印刷画面でプリンターまたはPDF保存を選びます。
画面表示と印刷用レイアウトは別に最適化されています。

## しおりをあとで開く

- 同じブラウザ: ホームの「最近のしおり」
- URLを受け取った: URLをそのまま開く
- ログイン中: マイページの「保存したしおり」
- 公開された旅程を探す: 「みんなのしおり」
- 手動保存: ブラウザのブックマーク

「最近のしおり」は端末のブラウザ内に保存されます。ログイン時の保存一覧とは別の仕組みです。
